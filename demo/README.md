# Demo RedAgro La Rioja

Red social productiva (vista comprador) + mapa real interactivo + vitrina + ministerio + trazabilidad.

## Abrir

Doble clic en `index.html`.

## Flujo

1. **Inicio** — feed como compradora: publicaciones, productos con fotos locales, consultas
2. **Mapa** — mapa real interactivo (Leaflet + Argenmap IGN / OpenStreetMap) sobre La Rioja
3. **Productor** — vitrina + mapa real del campo en Chilecito
4. **Ministerio** — bandeja de acreditación
5. **Trazabilidad** — BPA digital + asistente de ficha

Imágenes en `assets/img/` (locales, sin links rotos).
